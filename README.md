# VexCreamy Keys

Client-side Fabric mod for Minecraft Java 1.21.11.

Features:
- Pastel pink / cream keystrokes HUD in the top-right.
- WASD, Shift and Space indicators.
- Left/right mouse CPS counters.
- A soft vanilla UI click sound on keyboard key-down while Minecraft is focused.

## Build
Requires JDK 21 and Gradle 9.2+ (or a compatible Gradle version for Fabric Loom 1.14.1).
Run `gradle build`. The remapped mod jar is created in `build/libs/`.

Install the jar in the Minecraft `mods` folder alongside Fabric Loader and Fabric API for 1.21.11.
